# CS2063 - Fall 2026 - Course Labs

This repository contains the labs to be used in the CS2063 Fall 2026 course at UNB. 

NOTES: 
* New labs will be added as the semester goes on
* The lab examples make use of the Traditional Android UI (XML files) for the views

## Getting Started

### Android Studio
* The code examples are built against and run in Download Android Studio Quail 4 (2026.1.4)
* Should you use a different version you will be prompted to update the Gradle plugin used
   
### Android SDK
* For the most part the code uses API level 29 (Android Q 10.0)
* Please ensure that the correct SDK platforms are installed for the devices being used for testing

## Lab marking
Each lab will contain a list of deliverables which will need to be submitted upon completion.
